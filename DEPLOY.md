# Deploy na Vercel

1. Suba o CONTEÚDO desta pasta na raiz do repositório (package.json na raiz).
2. Vercel > Add New > Project > importe o repositório. Root Directory: vazio.
3. Environment Variables (NÃO crie NODE_ENV):
   - SUPABASE_SERVICE_ROLE_KEY = chave service_role (Supabase > Project Settings > API)
   - ADMIN_EMAILS = erickduraes0724@gmail.com
4. Deploy. Admin em /admin (login com a conta admin).
